# 無人機足球經賽營運系統（FIDA 復刻版）

依 FIDA 2022 國土交通部長官盃使用的經賽營運系統（[影片](https://www.youtube.com/watch?v=FwyhHYzZLeU)）復刻的網頁版計分系統，單一 `index.html`，不需安裝。

## 畫面
- `index.html` — 總覽控制室：紅隊／計分／藍隊三台螢幕、RED ZONE／BLUE ZONE 操作台、球門燈環、主審與副審遙控器
- `index.html#red-screen`、`#score-screen`、`#blue-screen` — 單獨全螢幕顯示，可拖到三台外接螢幕，同一台電腦的分頁即時同步
- `index.html#roster` — 名冊與隊伍設定（照片、隊徽、選手證卡號），資料存在瀏覽器，可匯出／匯入

## 流程
1. 選手感應選手證 → 按位置鈕入列（按錯重刷可覆寫）
2. 主審 ▶ 開賽，球門燈亮白燈
3. 副審記錄得分、防守犯規、進攻犯規（紅藍音效不同）
4. 賽中按自己位置鈕＝棄權；前鋒棄權時主審遙控器震動，交接完成按 STRIKER CHANGE
5. 主審 ❚❚ 終場，再按一次關燈；兩顆 STRIKER CHANGE 同按＝重置

## 硬體快捷鍵
| 裝置 | 按鍵 |
|---|---|
| 紅隊操作台 | `1`–`5`（Striker / Guide / Libero / Sweeper / Keeper） |
| 藍隊操作台 | `6`–`0` |
| 主審 | `G` 開始、`H` 終場／關燈、`Z` 紅前鋒交接、`X` 藍前鋒交接、`Z`+`X` 重置 |
| 紅隊副審 | `Q` 得分、`W` 得分−1、`A` 防守犯規、`S` 犯規−1、`D` 進攻犯規 |
| 藍隊副審 | `U` 得分、`I` 得分−1、`J` 防守犯規、`K` 犯規−1、`L` 進攻犯規 |
| RFID 讀卡機 | USB 鍵盤模式（卡號＋Enter） |
