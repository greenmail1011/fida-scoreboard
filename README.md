# 無人機足球計分系統（FIDA 復刻版）

新竹市無人機創新科技協會

依 FIDA 2022 國土交通部長官盃使用的競賽營運系統（[影片](https://www.youtube.com/watch?v=FwyhHYzZLeU)）復刻的計分系統，只保留計時、比分與犯規，單一 `index.html`，不需安裝。

網站：https://greenmail1011.github.io/fida-scoreboard/

## 畫面
- `index.html` — 總覽：計分螢幕預覽、球門燈環、主審與兩位副審遙控器、隊名與比賽時間設定
- `index.html#control` — 電腦操作面板：一台筆電用滑鼠／觸控就能操作整場
- `index.html#score-screen` — 計分螢幕全螢幕，拖到外接螢幕使用；同一台電腦的分頁即時同步

## 流程
1. 主審 ▶ 開賽，球門燈亮白燈
2. 副審記錄得分、防守犯規、進攻犯規（記在對手）；紅藍兩隊音效不同
3. 主審 ❚❚ 終場（時間到自動終場），再按一次關燈
4. RESET 按兩下重置，準備下一場

## 鍵盤
| 角色 | 按鍵 |
|---|---|
| 主審 | `G` 開始、`H` 終場／關燈、`Z`+`X` 同按重置 |
| 紅隊副審 | `Q` 得分、`W` 得分−1、`A` 防守犯規、`S` 犯規−1、`D` 進攻犯規 |
| 藍隊副審 | `U` 得分、`I` 得分−1、`J` 防守犯規、`K` 犯規−1、`L` 進攻犯規 |

## PS4 手把（PS5、Xbox 也可）
USB 或藍牙連上後，在總覽或電腦操作頁按任一鍵即可偵測，每支手把可指派角色：

| 角色 | 按鍵 |
|---|---|
| 單人全能 | Options 開始、Share 終場／關燈、觸控板 暫停、L1+R1 同按重置；十字鍵 ↑←→↓ = 紅隊得分／防守犯規／進攻犯規／得分−1，L2 犯規−1；△□○✕ = 藍隊同上，R2 犯規−1 |
| 主審 | ✕ 開始、○ 終場／關燈、Options 暫停、□ 復原、L1+R1 同按重置 |
| 副審 | ✕ 得分、△ 防守犯規、○ 進攻犯規、□ 得分−1、↓ 犯規−1 |

時間到自動終場時，主審手把會震動（需 Chrome 或 Edge）。

## 雲端同步（Firebase Realtime Database）
不連雲端時是「本機模式」，資料存在瀏覽器，同一台電腦的分頁會同步。

要讓多台裝置一起用（場館電腦當計分螢幕、裁判用手機或筆電操作）：
1. 在總覽或電腦操作頁上方輸入**房間代碼**（3–12 個英數字）和 **PIN**（4–12 字），按「連線」。新的代碼會自動建立房間，第一個連線的人設定 PIN。
2. 連線後會出現兩個連結：
   - 計分螢幕：`?room=代碼#score-screen`，開啟即觀看，不需要 PIN
   - 裁判遙控：`?room=代碼#control`，需輸入同一組 PIN 才能操作
3. 所有操作以 Firebase transaction 寫入，多位裁判同時按也不會互相覆蓋；計時以 Firebase 伺服器時間為準。

離線：沒有網路時照常計分，紀錄先存在該裝置（重新整理也不會遺失），網路恢復後自動上傳；斷線期間其他裝置也有更新時會自動合併。

安全規則：分數公開可讀；只有輸入正確 PIN 的裝置可以寫入；PIN 本身無法被讀取。
